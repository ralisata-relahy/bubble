Bubble project structure
========================

Architecture
------------
Code is organized using a feature-first Clean Architecture + MVC pattern:
- Model: Immutable domain entities, data catalogs, and business rules.
- View: Flutter screens, HUD overlays, and Flame custom rendering components.
- Controller: GetX controllers managing observable state and UI commands.
- Flame Engine: Authoritative owner of all real-time simulation (positions,
  velocities, collision passes, particle physics, and per-frame animations).
- GetX <-> Flame Boundary: High-level commands flow through the GameCommandPort
  interface; no per-frame physics variables are stored in Rx variables.
