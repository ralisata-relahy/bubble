# Audio

The app uses two audio paths:

- `sound_effect.dart` synthesizes short WAV effects with `sfx_generate.dart`,
  caches the generated bytes, and plays them through a small `audioplayers`
  player pool. `sound_sfx.dart` re-exports its `SoundEffects` and `Sfx` API.
- Question pronunciation is loaded as Flutter assets by the game feature's
  `GameAudioService`. These files must be present under `assets/audio/` and
  listed in `pubspec.yaml`.

The app imports the `bubble` package; the separate audio files and APIs are in
`lib/core/services/audio/`.

## Play a generated effect

The app creates and initializes a `SoundEffects` instance in `lib/main.dart`.
Pass that instance to consumers before calling `play`:

```dart
import 'package:bubble/core/services/audio/sound_sfx.dart';

final soundEffects = SoundEffects();
await soundEffects.init();
await soundEffects.play(Sfx.beamCorrect);
```

`play` accepts optional `volume` and `varyPitch` arguments. The service also
provides `startLoop`, `stopLoop`, `toggleLoop`, and a throttled `tick` helper.
Call `dispose()` when the audio service is no longer needed.

## Generate a WAV

`GameSfx` returns each effect as a `Uint8List` containing mono, 16-bit PCM WAV
data at 44.1 kHz:

```dart
import 'dart:io';

import 'package:bubble/core/services/audio/sfx_generate.dart';

Future<void> savePreview() async {
  final wavBytes = GameSfx.beamCorrect();
  await File('beam_correct.wav').writeAsBytes(wavBytes);
}
```

`SfxSynth` exposes `silence`, `sweep`, `tone`, `noise`, `softNoise`, `chime`,
`mix`, `delay`, and `toWav` helpers. `Wave` supports sine, square, saw, and
triangle oscillators. Generated effects are cached by `SoundEffects` during
initialization rather than regenerated for each playback.
